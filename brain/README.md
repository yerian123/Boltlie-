# My Second Brain

This is my personal knowledge vault — synced between Obsidian and GitHub.

Every time I start a new Claude chat, I point Claude here first so it has full context before we work.

---

## How to Use This With Claude

Paste this at the start of every new chat:

> "Before we start, read `brain/claude/context.md` in the `yerian123/Boltlie-` GitHub repo. That's my second brain — it has everything you need to know about me, my business, and what I'm working on. Read it first, then confirm you're ready."

---

## Folder Map

| Folder | What's In It |
|---|---|
| `/me` | Who I am, my background, values, how I think |
| `/business` | My businesses, models, offers, markets |
| `/projects` | Active projects, goals, what's in progress |
| `/claude` | The master context file Claude reads every chat |

---

## Maintenance

At the end of each Claude chat, ask:
> "Update the brain with anything new we covered today."

Claude will commit changes so the next chat starts fresh with the latest context.
